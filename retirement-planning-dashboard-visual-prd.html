Product decisions

MVP scope with implementation notes.

These choices keep the first build shippable while protecting clarity, speed, privacy, and explainability.

Area Decision Coding-agent annotation Tradeoff
App surface Single-page React/TypeScript dashboard. Build three functional zones: assumptions/accounts, chart/results, scenarios/export. Less routing complexity; export can start as a print view.
Calculations Deterministic monthly compound model. Keep projection logic in pure tested functions. Avoid UI-coupled math. Clear and fast; Monte Carlo stays future scope.
Storage Session-only by default. Do not persist client data silently. Explicit save only if added later. Better privacy story; less convenient for repeat meetings.
Social Security Manual monthly benefit input. Show whether Social Security is included in every income result and tooltip. Avoids inaccurate estimates; advisor needs outside estimate.
Charting Use a proven React chart library. Prefer Recharts for MVP; use ECharts if annotation/export needs grow. Faster than custom SVG; visual polish may need overrides.
Export Print-friendly summary first. Include assumptions, chart, results, date, and disclaimer. Reliable browser print now; PDF generation can follow.

Full MVP build prompt

            
Build the MVP retirement planning dashboard as a React/TypeScript single-page app for financial consultants using it live in client meetings.

Product intent:
- Let an advisor enter client assumptions, add accounts, compare scenarios, set annual retirement spending, toggle Social Security, and explain projected retirement outcomes visually.
- The UI should feel like a professional meeting tool, not a consumer calculator or spreadsheet.
- Prioritize speed, clarity, privacy, and explainability.

Design contract:
- Before making UI, component, color, spacing, chart, or print/export styling decisions, read DESIGN.md in this repository.
- The PRD controls product behavior and acceptance criteria. DESIGN.md controls visual identity, UI hierarchy, component styling, and interaction polish.
- Preserve the Innovest bronze/teal/lime color system, bronze inverted-triangle mark, and INNOVEST wordmark from DESIGN.md. Do not replace them with a generic dashboard palette.

BMAD execution requirement:
- Use the actual installed BMad Method BMM process in this repository before and during the build. Do not substitute a generic BMAD-style process.
- Before coding, verify _bmad/, .agents/skills/, and _bmad/_config/manifest.yaml exist.
- If BMAD is missing, run: npx.cmd bmad-method install --directory . --modules bmm --tools codex --yes
- If the codex tool id is rejected, run BMAD's tool-list command, choose the listed Codex tool id, and repeat the install.
- Start with bmad-help.
- Validate or update this PRD with bmad-validate-prd and bmad-edit-prd. If recreating the PRD from scratch, use bmad-create-prd.

- If BMAD recommends a PRD, UX, architecture, epic/story, test, or code change, record it, apply accepted changes to the correct artifact, and rerun the relevant BMAD validation, readiness, or code-review workflow before continuing.
- If BMAD cannot be installed, invoked, or verified, stop and report the blocker.

Recommended MVP design:
- Use the Innovest logo/wordmark as the visible top-of-app brand signal. Preserve the bronze inverted-triangle mark plus INNOVEST wordmark from this Visual PRD in the app masthead and print/export summaries.
- Advisor cockpit layout: left panel for assumptions/accounts, center area for projection chart and summary cards, right rail for scenarios, Social Security, annual retirement spending, and export/reset actions.
- Chart is the centerpiece. It shows projected total retirement assets by age/year with multiple scenario lines, retirement age marker, depletion marker, optional goal line, and Future dollars vs Today's dollars toggle.
- Summary cards show projected balance at retirement, inflation-adjusted balance, total contributions, estimated monthly retirement income, annual retirement spending, depletion age or no-depletion status, years funded, and remaining balance at projection end.
- Scenario management supports base scenario, duplicate, rename, remove, enable/disable from chart, and distinct colors.

Calculation requirements:
- Use pure TypeScript functions for monthly compounding.
- Convert annual return to monthly return: monthly_return = (1 + annual_return) ** (1 / 12) - 1.
- Apply monthly contributions, employer match when enabled, annual contribution increases, and monthly growth.
- Convert future dollars to today's dollars using inflation adjustment.
- Aggregate balances, total contributions, investment growth, and estimated monthly income.
- Use a simple withdrawal-rate method for income estimate, default 4%.
- Add annual retirement spending as a dollar input. Spending begins at retirement age, is withdrawn monthly, and increases annually with inflation by default.
- If Social Security is enabled, add monthly Social Security after start age as a spending offset. Portfolio withdrawal equals spending minus Social Security, never below zero. Do not invest Social Security surplus by default.
- Show depletion age/year when assets reach zero. If assets do not reach zero by the projection end age, show remaining balance and no-depletion status.
- Keep the withdrawal-rate income estimate visually separate from the actual annual-spending depletion path.

Privacy, branding, and export:
- Use the Innovest logo/wordmark at the top of the app and the print-friendly summary.
- Do not require real client names.
- Do not silently persist client data.
- Add Clear Session / Reset.
- Build a print-friendly summary first. Include date, optional client name, scenario names, key assumptions, annual retirement spending, depletion age or no-depletion status, chart, summary results, and this disclaimer:
"This projection is for informational purposes only and is not a guarantee of future performance. Actual results may vary based on market conditions, taxes, fees, inflation, contribution changes, withdrawals, and other factors."

Acceptance criteria:
- Advisor can create a base case in under 3 minutes.
- Advisor can add at least three accounts and three scenarios.
- Chart updates within 300ms for normal input changes.
- Today's dollars and Future dollars modes work.
- Social Security can be toggled per scenario.
- Annual retirement spending drives a post-retirement depletion path.
- Summary cards show depletion age, years funded, and remaining balance at projection end where applicable.
- Print summary needs no manual formatting.
- Core math functions have unit tests.
